記事カード管理

LP の「発信」セクションに表示する記事カードを編集します。
編集後、「🚀 本番に反映」ボタン1 つで GitHub に自動コミットされ、1〜2 分で本番ページに反映されます。

ℹ️ NOTE / YOUTUBE の記事カードは毎日自動更新されます（GitHub Actions）。X はローカル PC の xHermes タスクで半自動更新されます（最新3件）。このページでは SITE カードや例外的な X カードの手動管理を行ってください。

使い方

  1. 初回のみ: 上の「⚙ 設定」から GitHub のアクセストークン（PAT）を一度設定してください。以降は自動でブラウザに記憶されます。
  2. 右側フォームから記事を追加 / 左側一覧で編集・並び替え・削除。変更は自動でこのブラウザに保存されます。
  3. 「LP プレビュー」で見た目を確認。
  4. ページ下部の 🚀「本番に反映」をクリック → GitHub にコミット → 自動で反映を待機 → 完了通知

    GitHub で直接編集 ↗

    本番反映の設定

    「🚀 本番に反映」ボタンを使うには、GitHub の Personal Access Token (PAT) が必要です。トークンはこのブラウザの中だけに保存され、外部サーバには送信されません。

    1. トークンを作る

    1. GitHub の Fine-grained PAT 発行ページ を開く
    2. Token name: LP_Home admin（何でもOK）
    3. Expiration: お好み（推奨: 90 days 〜 1 year）
    4. Repository access: Only select repositories → yorozusoudansyo/home を選択
    5. Permissions > Repository permissions > Contents: Read and write
    6. 下の「Generate token」をクリック → 表示された文字列（github_pat_…）をコピー

    2. ここに貼り付け

    ⚠ このトークンはあなたのブラウザのみに保存されます。共有 PC では使用しないでください。
    使わなくなったら「トークンを削除」または GitHub 側で revoke してください。
